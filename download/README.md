Aero для Windows — сборки для скачивания
=========================================

Текущая версия (в корне этой папки, доступна на сайте):
- Aero-Setup-2.3.18.exe      — установщик в стиле Chrome/Edge (один экран
                               с опциями, установка в два клика, NSIS)
- Aero-Portable-2.3.18.exe   — портативная версия без установки

СЕРТИФИКАТ НИЧЕГО НЕ ТРЕБУЕТ. Скачивать сертификат отдельно больше НЕ нужно:
- Установщик сам добавляет сертификат «Aero Team» в доверенные хранилища
  Windows прямо во время установки — когда Windows спросит «Вы доверяете
  этому сертификату?», просто ответьте «Да» (один раз, без прав администратора).
- Портативная версия делает то же самое один раз при первом запуске.
- Все EXE подписаны сертификатом «Aero Team» (self-signed, sha256, timestamp
  DigiCert) — после ответа «Да» Windows перестаёт показывать «Неизвестный
  издатель» для Aero.

Хранение: сами EXE-файлы текущей версии также закоммичены в репозиторий
(в этой папке) — при сбоях инфраструктуры сборки восстанавливаются вместе
с проектом и не теряются.

Правило нумерации: номер версии только растёт и никогда не ниже уже
выданной пользователю сборки. Минимум на текущий момент: 2.3.18.

История версий (архив — папка archive/):
- 2.3.18 (2026-11-19): ПРОЩЕ И ПОНЯТНЕЕ. Настройки переработаны: боковое
  меню (как в системных настройках macOS) + сгруппированные карточки;
  все настройки стартовой страницы собраны в разделе «Стартовая» (фон,
  раскладка, виджеты, быстрый доступ) — гигантское окно настроек виджетов
  поверх всего браузера больше не существует. Панель инструментов больше
  НЕ перекрывает верх сайтов (контент начинается ниже тулбара).
  Редактирование стартового экрана: плавающая панель внизу, у карточек
  только размер и скрытие, порядок меняется перетаскиванием. Изменили
  размер/фон/виджет в настройках — открытая стартовая страница обновляется
  сразу. Модалки стали компактнее, пикер обоев — однострочным. Плюс всё
  из ранних превью 2.3.18: настоящие кнопки окна Windows вместо цветных
  точек, кнопка новой вкладки прижата к последней вкладке, поиск с
  главного экрана убран.
- 2.3.17 (2026-11-19): СКОРОСТЬ ЗАГРУЗКИ. Установщик пересобран с реальным
  LZMA-сжатием (был store — 83 МБ без сжатия из-за нехватки памяти при
  прошлой сборке) — файл меньше почти на треть и качается пропорционально
  быстрее. Сайт поддерживает докачку (HTTP Range): обрыв связи больше не
  заставляет скачивать заново с нуля. Интерфейс установщика и браузера не
  менялся — только упаковка и сайт.
- 2.3.16 (2026-11-18): СБОРКИ СНОВА ДОСТУПНЫ. Предыдущий приватный ключ
  подписи был потерян при сбое инфраструктуры (2.3.15 в файлах так и не
  вышел), поэтому выпущена 2.3.16: установщик и портативная версия
  пересобраны и подписаны свежим сертификатом «Aero Team» (10 лет, sha256,
  timestamp DigiCert, отпечаток F7:B5:77:C0:...:5E:C3:B0). Сертификат
  по-прежнему встроен в сами сборки: установщик сам добавляет его в
  доверенные хранилища Windows (одно подтверждение — «Да»), портативная
  версия — один раз при первом запуске. Отдельно качать сертификат не
  нужно.
- 2.3.15 (2026-11-18): СЕРТИФИКАТ ВСТРОЕН, НИЧЕГО КАЧАТЬ ОТДЕЛЬНО НЕ НУЖНО.
  Установщик автоматически ставит сертификат «Aero Team» в доверенные
  хранилища Windows (per-user, без админа; одно подтверждение Windows —
  «Да»). Портативная версия устанавливает сертификат один раз при первом
  запуске. Файлы Aero-CodeSign.cer и Установить-сертификат-Aero.cmd
  удалены из набора — они больше не нужны. Плюс: ротация сертификата
  (ключ снова утерян при сбросе песочницы — новый устанавливается
  автоматически, вручную доверяться не нужно); QA-прогон всех кнопок
  и внешнего вида лендинга и интерфейса браузера; секция «сертификат»
  на сайте переписана (теперь объясняет, что всё делается само).
- 2.3.14 (2026-11-18): ПЛАВНЫЕ АНИМАЦИИ. Новая система easing в стиле
  Apple (ease-out-quint cubic-bezier(.22,1,.36,1)) для всех появлений:
  вкладки, модалки, обзор, тосты, подсказки — движение стало мягким и
  дорогим. Переключатель-тумблер теперь анимируется transform'ом вместо
  layout-свойства left (GPU-композитинг, без reflow). Тень активной
  вкладки плавно перетекает (раньше появлялась мгновенно). Виджеты и
  карточки обзора вкладок появляются каскадом; при перерисовке
  (edit-mode, смена обоев, порядок виджетов) входные анимации больше НЕ
  переигрываются. Кнопки: равномерный press-feedback (scale .92,
  spring-fast). Поддержана системная настройка Windows «Уменьшить
  движение» (prefers-reduced-motion). Прокрутка внутренних областей без
  отдачи наверх (overscroll-behavior: contain). РОТАЦИЯ СЕРТИФИКАТА:
  приватный ключ подписи был случайно опубликован в открытом репозитории,
  поэтому выпущен НОВЫЙ сертификат «Aero Team» (отпечаток sha256
  02:F7:75:DA:...:19) — ОБЯЗАТЕЛЬНО запустите
  Установить-сертификат-Aero.cmd от имени администратора ещё раз,
  чтобы довериться новому сертификату.
- 2.3.13 (2026-11-18): ОКНО ДВИГАЕТСЯ + НАСТОЯЩЕЕ СТЕКЛО НАД САЙТАМИ.
  Перетаскивание: пустая область тайтлбара, тулбар и промежутки между
  вкладками теперь зоны захвата (раньше оставался только 10-пиксельный
  зазор — окно невозможно было сдвинуть). Стекло: сайты и внутренние страницы
  заходят ПОД хром и размываются им (как в Safari 27) — тинт хрома стал
  прозрачнее; выключение стекла в настройках теперь работает (класс
  body.glass ставится уже при старте). Скорость: отключён Known-тормоз
  Chromium на Windows (CalculateNativeWinOcclusion), погодный виджет
  получил 8-секундный таймаут. Сертификат обновлён (предыдущий ключ
  снова утерян при сбросе песочницы) — ЗАПУСТИТЕ
  Установить-сертификат-Aero.cmd ОТ АДМИНИСТРАТОРА ЕЩЁ РАЗ.
  Совет: для быстрого старта ставьте Setup, а не Portable — портативная
  версия распаковывается в temp при каждом запуске.
