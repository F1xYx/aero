Aero для Windows — сборки для скачивания
=========================================

Текущая версия (в корне этой папки, доступна на сайте):
- Aero-Setup-2.3.9.exe       — установщик в стиле Chrome/Edge (один экран
                               с опциями, установка в два клика, NSIS)
- Aero-Portable-2.3.9.exe    — портативная версия без установки

Правило нумерации: номер версии только растёт и никогда не ниже уже
выданной пользователю сборки. Минимум на текущий момент: 2.3.9.

История версий (архив — папка archive/):
- 2.3.9 (2026-11-15): полное QA-тестирование интерфейса (CDP-прогон:
  все кнопки, вкладки, виджеты, настройки — 14/14, 0 ошибок консоли).
  Добавлено восстановление сессии: тумблер «Открывать новую вкладку
  при запуске» теперь работает (при выключении браузер открывает
  вкладки прошлого запуска). Ctrl+Shift+Tab переключает на предыдущую
  вкладку. Исправлен сбой при быстром закрытии нескольких вкладок
  подряд (состояние вкладок рассинхронизировалось). localhost:порт в
  адресной строке открывается как сайт. Сайт: вместо скриншотов —
  живые анимированные отрисовки интерфейса прямо на странице.
- 2.3.8 (2026-11-15): браузер переименован Aera → Aero, новый логотип —
  стеклянный шар (иконки приложения, установщика, ярлыков). Ссылки
  aera:// остаются совместимы (распознаются наравне с aero://);
  партиция сессий persist:aera и ключи localStorage сохранены —
  настройки, история и логины на сайтах переносятся без потерь.
  Сайт проекта обновлён: парящие анимации при скролле, живое демо.
- 2.3.7 (2026-11-15): установщик переделан как у флагманских браузеров
  (один экран с логотипом, папкой и опциями ярлыков; без страницы
  лицензии, старых баннеров и страницы выбора режима установки).
  Починена навигация «Назад/Вперед» (стартовая страница и настройки
  входят в историю вкладки), невидимые стрелки ↑↓ в настройках
  виджетов, подсказки поиска за виджетами, «Свой фон» (prompt не
  поддерживается в Electron — теперь модальное окно), светлая тема
  стартовой страницы, кнопка «×» в адресной строке, Enter по выбранной
  подсказке, Ctrl+Shift+T (открыть закрытую вкладку), нейтральные
  карточки обзора вкладок, горизонтальные часы, корректные иконки
  разделов настроек.
- 2.3.6 (2026-11-15): фикс компоновки адресной строки (конфликт класса
  "newtab"), стандартный Chrome User-Agent, скриншоты, редизайн лендинга.
- 2.3.5 (2026-11-15): настройки как вкладка aera://settings, виджеты и
  их настройки, кастомный NSIS-установщик, редизайн лендинга.
- 2.3.4 (2026-11-15): восстановление после сброса песочницы, база 2.2.0.
- 2.2.2 и ранее — утеряны при сбросе песочницы; EXE у пользователя
  являются источником истины о выданных версиях.
