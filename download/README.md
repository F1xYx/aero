Aero для Windows — сборки для скачивания
=========================================

Текущая версия (в корне этой папки, доступна на сайте):
- Aero-Setup-2.3.13.exe      — установщик в стиле Chrome/Edge (один экран
                               с опциями, установка в два клика, NSIS)
- Aero-Portable-2.3.13.exe   — портативная версия без установки
- Aero-CodeSign.cer                  — публичный сертификат подписи Aero Team
- Установить-сертификат-Aero.cmd     — установка сертификата в доверенные
                                       хранилища Windows (запуск от админа)

Все EXE подписаны сертификатом «Aero Team» (self-signed, sha256, timestamp
DigiCert). Чтобы Windows не показывала «Неизвестный издатель» / «Открыть
всё равно» на этом компьютере — один раз запустите
Установить-сертификат-Aero.cmd от имени администратора.

Правило нумерации: номер версии только растёт и никогда не ниже уже
выданной пользователю сборки. Минимум на текущий момент: 2.3.13.

История версий (архив — папка archive/):
- 2.3.13 (2026-11-18): ОКНО ДВИГАЕТСЯ + НАСТОЯЩЕЕ СТЕКЛО НАД САЙТАМИ.
  Перетаскивание: пустая область тайтлбара, тулбар и промежутки между
  вкладками теперь зоны захвата (раньше оставался только 10-пиксельный
  зазор — окно невозможно было сдвинуть). Стекло: сайты и внутренние страницы
  заходят ПОД хром и размываются им (как в Safari 27) — тинт хрома стал
  прозрачнее; выключение стекла в настройках теперь работает (класс
  body.glass ставится уже при старте). Скорость: отключён Known-тормоз
  Chromium на Windows (CalculateNativeWinOcclusion), погодный виджет
  получил 8-секундный таймаут. Сертификат обновлён (предыдущий ключ
  снова утерян при сбросе песочницы) — ЗАПУСТИТЕ
  Установить-сертификат-Aero.cmd ОТ АДМИНИСТРАТОРА ЕЩЁ РАЗ.
  Совет: для быстрого старта ставьте Setup, а не Portable — портативная
  версия распаковывается в temp при каждом запуске.
- 2.3.12 (2026-11-15): СВОЙ КРАСИВЫЙ УСТАНОВЩИК — финальный фикс: галочки
  в установщике больше не обрезаются (строки опций 14u вместо 10u — запас
  для масштабирования Windows 125–150%, короткие лейблы, длинное пояснение
  вынесено в подсказку); логотип-баннер теперь масштабируется по ширине
  окна (NSD_SetStretchedImage вместо обрезаемого NSD_SetImage); кнопка
  «Обзор…» больше не наезжает на поле пути; новый нарисованный стеклянный
  баннер (логотип, воркмарк, пилюля версии, мягкая аура); заголовок окна
  «Aero — установка»; кнопки «Установить Aero» / «Готово».
- 2.3.11 (2026-11-15): перевыпуск дистрибутивов. Сборки 2.3.10 были
  собраны и подписаны, но при сбросе песочницы EXE-файлы и приватный
  ключ подписи были потеряны — сборки пересобраны и подписаны НОВЫМ
  сертификатом «Aero Team» (тот же издатель, срок 10 лет, sha256,
  timestamp DigiCert). Версия бампа до 2.3.11, чтобы не путать файлы.
  ВАЖНО: если ранее устанавливали старый Aero-CodeSign.cer — запустите
  Установить-сертификат-Aero.cmd ещё раз от имени администратора,
  чтобы доверился новый сертификат.
- 2.3.10 (2026-11-15): НАСТОЯЩЕЕ ЖИДКОЕ СТЕКЛО — тайтлбар и тулбар теперь
  парят над контентом с backdrop-blur (обои стартовой страницы и градиент
  настроек заходят под хром, как в Safari 27); интенсивность стекла
  (низкая/средняя/высокая) влияет и на хром; сборки подписаны сертификатом
  Aero Team; сайт полностью переделан: стеклянные летающие окна-мокапы,
  scroll-анимации, без единого скриншота браузера.
- 2.3.9 (2026-11-15): полное QA-тестирование интерфейса (CDP-прогон:
  все кнопки, вкладки, виджеты, настройки — 14/14, 0 ошибок консоли).
  Восстановление сессии (тумблер «Открывать новую вкладку при запуске»).

- 2.3.6 (2026-11-15): фикс адресной строки, стандартный Chrome UA, редизайн.
